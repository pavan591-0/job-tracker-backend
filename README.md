# Job Tracker Backend

Spring Boot backend application to track job applications.

## Tech Stack
- Java 17
- Spring Boot
- Spring Data JPA
- H2 (tests)
- PostgreSQL (local)
- JUnit, MockMvc
- GitHub Actions (CI)
